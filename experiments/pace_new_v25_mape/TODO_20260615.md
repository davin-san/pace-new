# PACE v25 MAPE Execution TODO

Goal: validate a one-full-system-extraction workflow that transfers traffic to
new network designs while keeping avg and p99 network latency near or below 5%
MAPE against gem5 v25.1 full-system.

## Current Acceptance Gates

- pace-new Garnet source remains byte-identical to gem5 Garnet.
- Changes stay in compat, profile tooling, experiment scripts, or gem5
  instrumentation used only for extracting ground-truth profiles.
- Same-topology profile replay must be below 5% avg and p99 error.
- If predicted-demand transfer fails but oracle-demand transfer passes, the
  demand feedback model is the problem.
- If oracle-demand transfer fails, profile composition or topology replay is
  the problem.
